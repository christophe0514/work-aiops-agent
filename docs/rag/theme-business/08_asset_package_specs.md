# 主题素材包规范

适用场景：解释素材上传失败、资源包校验失败、预览图缺失、适配异常  
关键词：素材包、资源包、manifest、预览图、封面图、CDN、适配

## 素材组成

一个完整主题通常包含：

- 主题资源包
- 主题封面图
- 主题预览图
- 详情页长图或介绍图
- 图标资源
- 锁屏资源
- 壁纸资源
- 字体资源
- manifest 配置文件

不同终端对素材要求不同，Android、iOS、HarmonyOS 不能完全复用。

## 资源包要求

资源包通常为 zip 格式。

基础要求：

- 能正常解压。
- 文件名不能包含特殊控制字符。
- 目录层级不能过深。
- 单文件大小不能超过平台限制。
- 总包大小不能超过平台限制。
- 不能包含可执行文件。
- 不能包含外部下载脚本。
- 必须包含 manifest 配置。

## manifest 要求

manifest 是主题资源包的核心配置文件。

常见字段：

- themeId
- packageVersion
- minClientVersion
- terminalType
- iconResources
- wallpaperResources
- lockScreenResources
- previewResources
- checksum

常见错误：

- manifest 缺失。
- JSON 格式错误。
- packageVersion 低于线上版本。
- 声明的资源文件不存在。
- checksum 和实际文件不一致。
- terminalType 和上架终端不一致。

## 预览图规范

预览图用于前台详情页、列表页、活动页展示。

常见要求：

- 封面图清晰，不拉伸。
- 列表图尺寸符合渠道规范。
- 详情图能准确展示主题效果。
- 不得包含二维码、联系方式、外链。
- 不得包含虚假按钮或诱导点击元素。
- 预览图应和实际主题效果一致。

预览图缺失会导致审核失败或渠道同步失败。

## 适配问题

主题上架后出现显示异常，常见原因包括：

- 客户端版本低，不支持新资源格式。
- 资源包声明的最小版本过高。
- 图片比例不适配目标分辨率。
- 横屏资源缺失。
- 深色模式资源缺失。
- 字体颜色和壁纸背景对比度不足。

## CDN 分发

资源包审核通过后，需要分发到 CDN。

CDN 分发异常表现：

- 详情页能打开但下载失败。
- 预览图加载失败。
- 部分地区资源下载慢。
- Android 可下载但 iOS 下载失败。

处理建议：

- 查询 CDN 上传状态。
- 检查资源 URL 是否生成。
- 检查文件 MD5。
- 必要时重新触发资源分发。

## 常见问法

### “素材上传失败是什么原因？”

可能原因：

- 包格式不正确。
- 包内文件过大。
- manifest 缺失或格式错误。
- 包含禁止文件类型。
- 网络上传超时。

### “审核通过后为什么下载失败？”

可能原因：

- CDN 分发失败。
- 资源 URL 过期。
- 下载鉴权失败。
- 当前终端没有对应资源。

### “预览图和实际效果不一致会怎么样？”

回答建议：

> 预览图和实际效果不一致会影响用户判断，通常会被人工审核驳回。已上架主题如果被投诉，也可能触发下架或复审。
