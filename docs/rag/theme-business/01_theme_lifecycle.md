# 主题生命周期说明

适用场景：解释主题从创建到上架、下架、复审的业务流程  
关键词：主题生命周期、创建、提交审核、审核通过、上架、下架、复审

## 生命周期总览

主题平台中的一个主题通常会经历以下阶段：

```text
草稿创建
  -> 素材上传
  -> 预校验
  -> 提交审核
  -> 机器审核
  -> 人工审核
  -> 审核通过
  -> 上架配置
  -> 渠道同步
  -> 前台可见
  -> 运营调整或下架
```

并不是每个主题都会完整经过所有阶段。内部自营主题、活动主题、合作方定制主题可能会走不同的审核策略。

## 草稿创建

商户或运营人员在主题后台创建主题后，系统生成主题 ID。此时主题处于草稿状态，前台不可见，也不会进入审核队列。

草稿状态常见特征：

- 可以编辑主题名称、简介、标签、分类。
- 可以上传或替换素材包。
- 可以删除草稿。
- 不会产生审核记录。
- 不会同步到前台搜索、推荐或活动页。

如果运营问“为什么新建主题查不到审核状态”，通常是因为主题还没有提交审核。

## 素材上传和预校验

提交审核前，系统会对素材做基础校验。预校验失败不会进入正式审核。

常见预校验项：

- 主题包是否完整。
- 必填尺寸的预览图是否上传。
- 资源包是否能正常解压。
- `manifest.json` 是否存在。
- 主题包版本号是否符合规范。
- 是否包含禁止上传的文件类型。
- 是否命中病毒扫描或敏感文件扫描。

预校验失败时，主题状态通常仍停留在草稿或待提交，审核状态不会变为待审核。

## 提交审核

主题提交审核后，会生成一条审核单。系统会记录提交人、提交时间、主题版本、审核类型和审核来源。

审核类型一般包括：

- 首次审核：新主题第一次提交。
- 更新审核：已上架主题修改素材或基础信息后再次提交。
- 复审：被驳回后修改重新提交。
- 风控复审：上架后因投诉、巡检、政策变化触发。

提交审核后，运营一般不能直接编辑已提交的版本，只能撤回或等待审核结果。

## 机器审核

机器审核主要检查明确规则，包括敏感词、图片涉政涉黄、版权黑名单、资源包安全扫描、格式合法性等。

机器审核通过后会进入人工审核。机器审核不通过时，系统通常会直接给出规则命中的驳回原因。

## 人工审核

人工审核由审核人员检查主题内容质量、版权说明、视觉一致性、分类是否合理、是否符合平台运营规范。

人工审核结果一般包括：

- 通过
- 驳回
- 需补充材料
- 转高级审核
- 挂起

如果状态长时间停留在人工审核中，可能是审核队列积压、节假日审核人力不足或主题命中了高级审核规则。

## 审核通过

审核通过只代表主题内容满足平台审核要求，不代表已经前台可见。前台可见还需要满足上架配置、渠道同步、售卖配置、缓存刷新等条件。

运营提问“审核通过为什么看不到”时，不能直接回答“系统异常”，应该继续判断：

- 是否已经配置上架渠道。
- 是否到达定时上架时间。
- 是否被活动或地域规则限制。
- 是否售卖状态有效。
- 是否同步到前台索引。
- 是否存在缓存延迟。

## 上架配置

审核通过后，运营需要配置上架范围。常见配置包括：

- 上架渠道
- 终端类型
- 分类位置
- 标签
- 售卖方式
- 上架时间
- 下架时间
- 地域范围
- 会员权益

没有上架配置的主题，即使审核通过，也不会出现在前台。

## 渠道同步

主题上架后，后台会将主题数据同步到前台系统、搜索索引、推荐系统、活动系统、资源 CDN 等模块。

同步通常是异步的，因此审核通过或点击上架后，前台可能有 1 到 10 分钟延迟。大促期间或批量上架时可能延迟更久。

## 下架和复审

主题下架后前台不可购买或不可下载，但历史已购用户是否还能使用取决于下架类型。

常见下架类型：

- 运营主动下架：一般不影响历史已购用户。
- 版权投诉下架：可能限制再次下载。
- 风控强制下架：可能限制展示、购买和下载。
- 到期自动下架：通常由上架结束时间触发。

已下架主题重新上架时，若素材、名称、版权、价格发生变化，通常需要重新审核。
