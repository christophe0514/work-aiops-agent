# 主题上架失败原因说明

适用场景：解释主题为什么上架失败、部分渠道失败、同步失败  
关键词：上架失败、发布失败、同步失败、渠道失败、CDN失败、索引失败

## 上架失败分类

主题上架失败一般分为以下几类：

- 配置类失败
- 审核状态类失败
- 渠道同步类失败
- 资源分发类失败
- 售卖配置类失败
- 权限或风控类失败
- 系统异常类失败

## 配置类失败

### 未选择上架渠道

主题审核通过后，如果没有选择任何上架渠道，上架任务无法生成。

处理建议：

- 补充上架渠道。
- 检查是否配置主题商店、会员中心、活动页等目标渠道。

### 上架时间配置错误

常见错误：

- 上架结束时间早于开始时间。
- 上架时间早于当前时间但未允许立即发布。
- 时间格式或时区错误。
- 活动页要求在活动周期内上架，但主题时间超出活动周期。

处理建议：

- 修正上架开始和结束时间。
- 确认系统使用北京时间还是 UTC。

### 分类缺失

主题商店通常要求配置一级分类和二级分类。缺少分类会导致同步前台失败。

处理建议：

- 补充分类。
- 避免选择已下线分类。

## 审核状态类失败

### 当前版本未审核通过

上架必须使用审核通过的版本。如果运营编辑了主题信息但未重新审核，可能会出现“后台显示曾经通过，但当前版本不可上架”。

处理建议：

- 查询当前版本号和审核版本号是否一致。
- 对当前版本重新提交审核。

### 审核结果被风控撤销

上架前如果主题命中风控策略，审核通过状态可能被撤销或挂起。

处理建议：

- 查询风控记录。
- 确认是否有投诉、版权争议或巡检命中。

## 渠道同步类失败

### 前台商品中心同步失败

主题上架需要同步商品中心。如果商品中心没有生成商品记录，前台无法展示或购买。

常见原因：

- 商品 ID 已存在但状态异常。
- 商户信息缺失。
- 售卖方式不被该渠道支持。
- 商品中心接口超时。

### 搜索索引同步失败

主题已上架但搜索不到，可能是搜索索引同步失败。

常见原因：

- 主题标题为空或被过滤。
- 分类字段缺失。
- 搜索服务积压。
- 索引任务重试失败。

### 推荐系统同步失败

推荐位、分类页、活动页可能依赖推荐系统。如果推荐同步失败，详情页可打开但列表页不展示。

处理建议：

- 查询推荐任务状态。
- 检查主题是否满足推荐位规则。

## 资源分发类失败

### CDN 上传失败

资源包需要上传到 CDN。上传失败时，主题无法下载或预览图无法展示。

常见原因：

- 资源包过大。
- 文件名含特殊字符。
- 文件路径过长。
- CDN 接口超时。
- 上传凭证过期。

处理建议：

- 重新触发资源分发。
- 检查资源包大小和文件名规范。

### 资源包校验失败

即使审核通过，上架时仍可能进行最终资源校验。

常见原因：

- 审核后资源包被替换。
- 文件 MD5 和审核记录不一致。
- manifest 引用的文件不存在。
- 资源包下载地址失效。

## 售卖配置类失败

### 价格未配置

付费主题必须配置价格。没有价格会导致商品不可售或上架失败。

### 价格未生效

价格有生效时间。主题上架时间早于价格生效时间时，可能出现前台不可购买。

### 会员权益冲突

同一主题同时配置付费、限免、会员专享时，可能产生权益冲突。

处理建议：

- 明确售卖方式优先级。
- 检查限免时间和会员权益时间是否重叠。

## 权限或风控类失败

### 商户被冻结

商户状态异常时，主题不能上架。

常见状态：

- 商户被冻结。
- 商户合同过期。
- 商户未完成资质认证。
- 商户结算账户异常。

### 版权授权过期

如果版权授权有效期早于上架结束时间，系统可能拒绝上架。

处理建议：

- 缩短上架时间。
- 补充新的授权证明。

## 系统异常类失败

系统异常通常表现为接口超时、任务重试失败、消息队列积压、数据库写入失败。

处理建议：

- 查看上架任务 ID。
- 查询同步日志。
- 查询失败节点。
- 如为临时超时，可重试发布。
- 如为数据不一致，需要开发支持修复。

## 回答模板

当用户问“主题为什么上架失败”时，建议回答：

> 上架失败通常需要区分失败节点。请先确认该主题是否已审核通过、是否配置上架渠道和时间、资源包是否完成 CDN 分发、商品价格是否生效，以及目标渠道同步是否成功。如果能提供主题 ID，我可以进一步定位失败节点和具体原因。
